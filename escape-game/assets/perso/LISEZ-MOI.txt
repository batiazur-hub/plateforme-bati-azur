DOSSIER DE VISUELS PERSONNELS
=============================

Deposez ici vos propres images : elles remplaceront automatiquement les
visuels generes par le code, au prochain `python render.py`.

Emplacements disponibles :

  les quatre ecus de la carte 4
  le filigrane du certificat (carte 12)

INUTILE DE RENOMMER VOS FICHIERS
--------------------------------
Il suffit que le nom du fichier CONTIENNE le nom de la maison, en francais ou
en anglais, quelles que soient les majuscules, accents ou ponctuations. Tous
ces noms sont reconnus :

  Gryffindor-crest-vector-01.png      -> ecu de Gryffondor
  poufsouffle.png                     -> ecu de Poufsouffle
  Ravenclaw_Crest_HQ.png              -> ecu de Serdaigle
  blason-serpentard.svg               -> ecu de Serpentard
  hogwarts-castle.jpg                 -> filigrane du certificat

Mots-cles : gryffondor/gryffindor, poufsouffle/hufflepuff,
serdaigle/ravenclaw, serpentard/slytherin, filigrane/watermark/poudlard/
hogwarts.

Extensions acceptees : .svg .png .jpg .jpeg .webp .gif

Vous pouvez n'en deposer qu'un ou deux : les maisons sans fichier gardent
l'ecu heraldique genere par le programme. `render.py` affiche au demarrage la
liste des fichiers qu'il a reconnus.

Conseils d'impression :
  - PNG a fond transparent, cote le plus long >= 600 px.
  - Pour le filigrane, une image claire : elle est posee a 10 % d'opacite
    sous du texte que l'on remplit a la main.

IMPORTANT
---------
Ce dossier est exclu du depot Git (voir .gitignore) : son contenu reste sur
votre machine et n'est pas publie. C'est voulu. Un visuel sous droit d'auteur
utilise chez soi pour une partie entre amis releve de l'usage prive ; le meme
fichier pousse sur un depot public devient une publication, ce qui est une
autre affaire. Le mecanisme est versionne, les images ne le sont pas.
